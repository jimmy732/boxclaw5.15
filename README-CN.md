# 策锐锻造中国官网

本项目是独立运行的纯中文国内官网，默认端口为 `4188`，本地运行时数据固定保存在项目自身的 `work/runtime-cn`，不与 4174 海外站共用。

## 启动

在 PowerShell 中运行：

```powershell
& 'C:\Users\ADMINHT\Documents\ChatGPT\forcar\cerui-cn-site\start-cn.ps1'
```

打开：`http://127.0.0.1:4188/`

## 已包含

- 首页视觉系统直接按 Wheelforce 的实测 UI/CSS 结构重建：67px 悬浮导航、1236px 栅格、居中首屏、车型选择、黑白交替分区、产品陈列、2×2 图片入口、视频/总部区和信息型页脚；不沿用原外贸站首页设计。
- 首页真实轮毂持续旋转、指针视差与降低动态效果偏好支持。
- 基于策锐企业资料整理的杭州总部、轮毂工厂与全国直营网点/代理网络地图。
- 三段随附视频的浏览器兼容版本及封面图。
- 保留原外贸站的轮毂适配实验室、参数计算、款式优先/参数优先双流程与上车效果生成功能。

## 上线信息

- 当前资料仅能确认一个杭州总部、一个自有轮毂工厂及九个直营网点/代理城市；仓库数量与具体地址没有在已提供材料中完整列明。
- 正式域名：`https://crforged.cn/`
- 后台入口：`https://crforged.cn/admin/`
